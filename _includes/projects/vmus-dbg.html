vMUS‑dBG

A variable‑length de Bruijn graph for de novo genome assembly — PhD dissertation, 2026

Every de Bruijn graph assembler makes the same compromise: pick one k. Small k collapses repeats; large k shatters unique sequence. vMUS‑dBG removes the choice.

Instead of fixed‑length k‑mers, each graph node is a Minimum Unique Substring (MUS) — the shortest substring at a position that is unique in the read set and cannot be shortened on either side without losing that uniqueness. MUS length adapts to the genome itself: short in unique regions, long exactly where it must span a repeat boundary. Edges carry the maximal repeat (or gap sequence) lying between consecutive MUSs in a read, so a single assembly run resolves both unique and repetitive regions.

The model builds on the duality between MUSs and maximal repeats (Ilie & Smyth) and the Manifold / A‑Bruijn graph (Lin & Pevzner), and extends them to fragmented, error‑prone reads through a read‑consistent definition of uniqueness.

// how it works
  • Linear‑time extraction of MUS boundaries and maximal repeats in O(N), via a generalised suffix tree (Ukkonen) or a lower‑memory suffix array + LCP backend (SA‑IS + Kasai).
  • Iterative read correction (substitutions and indels) voted from overlap evidence with coverage‑adaptive thresholds, restoring read consistency before extraction.
  • Per‑position consensus for gap sequences and node overhangs, plus post‑assembly polishing that re‑aligns every contributing read.
  • Coverage‑adaptive graph resolution, so genuine low‑coverage regions survive alongside noise removal; PAF‑guided and KMP suffix/prefix scaffolding join residual contigs.
  • Self‑contained: uses minimap2 when present, otherwise falls back to internal k‑mer seed‑and‑extend overlaps.

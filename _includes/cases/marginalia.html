Marginalia

AI Exam Script Marking

Scan a handwritten script and get a criterion‑by‑criterion draft mark, which a teacher approves before anything is released.

It reads scanned handwriting, typed documents or source code, splits a booklet into per‑question answers, and marks each against one of seven rubric types: analytic, holistic, calculation, open, report, essay and code.

As much as possible is plain Python rather than a model's judgement. Final numeric answers, units and significant figures are checked symbolically, and code is run against the teacher's tests in an isolated container, so a remark gives the same numbers and costs no AI quota. Weighted course grades keep provisional and final scores apart and never treat a missing mark as zero.
